# 02-游戏学习 · 俯视角生存射击游戏

> 一个用 **Godot 4** 制作的俯视角生存射击小游戏（学习项目）。
> 玩法灵感来自《星露谷物语》中的小游戏「草原之王之旅」（Journey of the Prairie King）：
> 在倒计时结束前活下来——移动、走位、射击，拾取强化道具在越来越密的敌潮中求生。

## 🎮 玩法简介

- **目标**：存活到 60 秒倒计时结束即为胜利；生命值归零则失败。
- **操作**：WASD 移动，方向键八方向独立射击（可以边跑边打）。
- **敌人**：多种敌人会追踪玩家、接触造成伤害，死亡后按概率掉落强化道具。
- **强化**：拾取道具获得限时 Buff——加速、射速翻倍、甚至变身「武装强化形态」。
- **节奏**：剩余时间越少，敌人刷新越快，压力逐步升级。

## 🕹️ 操作方式

| 按键 | 功能 |
| --- | --- |
| `W` / `A` / `S` / `D` | 上下左右移动 |
| `↑` / `↓` / `←` / `→` | 对应方向射击（与移动方向互相独立） |
| 结算窗口 → `结束游戏` / `Enter` | 结束本局并退出游戏 |

> 设计亮点：移动与射击方向解耦，可以「边往后跑边朝前打」，这是生存射击的核心操作手感。

## 🧩 游戏机制

### 敌人（数据驱动）

所有敌人均由 `resources/config/enemy_*.tres` 配置驱动，改数值即改玩法，不用动代码。

| 敌人 | 生命 | 速度 | 特点 | 掉落率 |
| --- | --- | --- | --- | --- |
| 基础敌人 | 3 | 20 | 普通近身敌人，追着玩家撞 | 20% |
| 带壳敌人 | 6 | 10 | 血厚皮糙，行动缓慢 | 80% |
| 快速敌人 | 2 | 30 | 高速突进，非常难躲 | 50% |
| 自爆敌人 | 2 | 15 | 死亡后自爆，范围伤害波及玩家*和周围的敌人* | 80% |

- 敌人死亡时会播放死亡动画，自爆敌人还会进入第二段「爆炸」流程。
- 掉落使用**加权随机**（`drop_weight`），不同敌人可配置不同的掉落表。
- 场上敌人数量有上限（默认 12），避免无限堆积。

### 道具（Buff）

| 道具 | 效果 | 说明 |
| --- | --- | --- |
| 移速道具 | 移动速度 ×2.0 | 持续 5 秒 |
| 射击道具 | 射速 ×2.0 | 持续 5 秒，开火间隔减半 |
| 强化道具 | 变身「武装形态」 | 自动发射**双向螺旋弹幕**，身体切换武装动画并召唤浮游炮特效 |

- 道具临近消失时会闪烁预警，超时自动销毁。
- `duration <= 0` 可配置为永久生效（当前配置均使用 5 秒限时）。

### 子弹

- 每物理帧移动前会用**射线查询**覆盖「本帧路径」，高速下也不会穿墙。
- 命中敌人造成 1 点伤害；子弹之间可互相穿过；超时（2 秒）自动销毁。

## 🚀 运行方法

1. 安装 **Godot 4.7+**（原生 GDScript 项目，无需任何外部依赖）。
2. 使用 Godot 打开本目录（`project.godot`）。
3. 按 `F5` 运行，或命令行：`godot --path .`
4. 主场景：`res://scene-场景/game-场景文件.tscn`（已在项目中设置为默认主场景）。

## 📦 导出

项目已配置 **Windows Desktop** 导出预设，产物输出到 `../导出游戏/`：

- 编辑器 → 项目 → 导出 → Windows Desktop → 导出项目
- 命令行：`godot --headless --path . --export-release "Windows Desktop"`

## 🎓 学习要点（本项目注释即教程）

每个脚本都带有**逐行中文教学注释**，覆盖以下 Godot 核心技巧：

- `CharacterBody2D` + `move_and_slide()` 角色移动与碰撞滑行
- **物理层（collision layer / mask）** 与二进制掩码的正确用法
- `Area2D` 信号驱动的接触伤害 / 拾取 / 子弹命中
- **射线查询（`intersect_ray`）** 防止高速子弹「隧道效应」穿墙
- **数据驱动设计**：用 `Resource` 子类和 `.tres` 配置文件做敌人/道具参数，策划改数值不用碰代码
- 状态机式死亡流程：普通敌人「死亡动画 → 销毁」，自爆敌人「死亡动画 → 爆炸 → 销毁」
- 加权随机掉落表（`drop_weight`）
- 着色器参数驱动的受击 / 到期闪烁
- HUD 按视口宽度等比锚定，窗口缩放 / 全屏不变形
- `Engine.time_scale = 0` + 场景树暂停的结算处理
- `@onready` 与节点生命周期、`call_deferred` / `set_deferred` 延迟调用的正确时机
